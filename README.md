# Kiroween 2026: Legends

A horror lore engine and two apps built from it: a worldwide legends atlas and a single-player investigation game that cannot be solved without reading the atlas. Entry for the Kiroween 2026 hackathon, Skeleton Crew category.

## Folders

- `skeleton/`: the shared lore engine (content packs, seeded randomness, puzzle generator, hints, theme packs, auth and progress).
- `apps/atlas/`: the public legends atlas.
- `apps/game/`: the single-player investigation game.

Story content lives in `content/`, images in `assets/`, planning and decisions in `docs/`.
