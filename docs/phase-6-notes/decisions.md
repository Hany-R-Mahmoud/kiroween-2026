## Rule: steering wins

## Conflicts between design-direction.md and the steering files (accepted by the Owner)

1. **Display font.** Steering names `IM Fell English SC`; the direction splits `IM Fell English` (above 20 px) and SC (12 to 14 px kickers). Chosen: headings keep `IM Fell English SC`. Both families are in `KNOWN_FONTS`, so the split stays a later option.
2. **Palette.** Steering fixes the hub palette and forbids redefining base tokens. The direction adds a paper pair, ember, a raised surface and rule tokens. Chosen: add new tokens beside the base palette; never change a base value.
3. **Paper ink values.** Phase 5 pins book ink `#2b1d12` and accent `#4a1c12` (`skeleton/src/book/bookColors.ts`, `book.css`, `book-colors.property.test.ts`); the direction proposes `#2a1d12`. Chosen: keep the pinned values unless a measured pair fails AA; if one must move, change TypeScript, CSS and test together.
4. **Map.** The atlas spec and Phase 3 plan keep the painted map as a decorative band without markers; the direction wants it as the one map. Options: (a) remove the Painted_Strip, keep the real `WorldMap`; (b) make the painted map the real map. Chosen: (a), the smallest. Revisit only if the design phase shows the pins align with the painted image.
5. **Scope of the direction.** Extra pages and parts (How every legend is told strips, featured legend, crossover band, About page, chapter rail, game door grid from panorama crops, "Show hotspots" toggle, icon plates) stay out of scope unless a P1 or P2 item names them.
