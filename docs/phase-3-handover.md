## Deep links and `atlasUrl`

- Every stored anchor is the id of exactly one element on its legend page:
  - `<id>--ch-<n>` on the chapter section;
  - `<id>--versions` on the versions section;
  - `<id>--versions--<v>` on that version.
- The URL is `/legends/<legend-id>#<anchor>`.
- `/anchor/<anchor>` checks the format first (`ANCHOR_RE`, at most 120 characters), so a malformed anchor never reaches a query. A stored anchor gets a 307 to that URL; an unknown or malformed one gets the 404 page.
- `atlasUrl(anchor)` (skeleton, browser-safe) returns the root-relative URL and throws on a malformed anchor. `legendUrl(id)` gives `/legends/<id>`. The game will call `ATLAS_ORIGIN + atlasUrl(hint2Anchor)` in Phase 4.
- Landing: the browser or router scrolls; `AnchorFocus` moves focus to the section heading and marks it for 2 seconds. Smooth scrolling and the glow happen only with no reduced-motion preference; otherwise a static outline.
- Not covered yet: `keepers-note--ch-1` gets 404 until the Keeper's Note is imported in Phase 4. The anchor and render tests cover the 12 legend files only.

## How images and fonts are served

- **Images:** `assetUrl(id)` (skeleton) maps an id to `/media/<legend>/<surface>/<id>.webp`, `/media/hub/…` or `/media/shared/…`, following `assets/README.md`.
  - In dev, a Vite plugin serves only a request that equals `assetUrl` of its file name.
  - At build time, the 423 files are copied into `dist/client/media/`. That is build output; the repo is unchanged.
  - Every image has its real width and height; a test reads each WebP header. The hero is preloaded with high priority; everything else is lazy.
  - Alt text comes from stored text. Plates: "Illustration for chapter n: \<title\>". Hero: "\<title\>: hero illustration". Marker: "\<title\>". The home hero and the painted map are decorative (`alt=""`).
- **Fonts:** self-hosted Fontsource stylesheets (400, plus 400 italic where it exists), linked only for the page's own families, with `unicode-range` subsets and `font-display: swap`. No third-party CDN is used.
