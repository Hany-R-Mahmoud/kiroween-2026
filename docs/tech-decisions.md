## Database connections

Two variables, both read from the environment only and never printed or logged:

- `DATABASE_URL`: the pooled string (PgBouncer, transaction mode). For app runtime in later phases.
- `DATABASE_URL_UNPOOLED`: the direct string. Used by `drizzle-kit migrate` and the content import script.

Reason: Neon's connection-pooling documentation lists schema migrations as a direct-connection use case, and transaction-mode pooling does not support session-level features. Both names are in `.env.example` with no values.

## Other choices

- `scripts/check-legend.mjs` is plain Node with no dependencies, so the content hook works before any install.
- Neon Auth variable names in `.env.example` are confirmed by the owner: `NEON_AUTH_BASE_URL` and `NEON_AUTH_JWKS_URL` come from the Neon console; `NEON_AUTH_COOKIE_SECRET` is generated by the owner.
- Neon MCP server: name `Neon`, type `http`, url `https://mcp.neon.tech/mcp`, authenticated by the owner, kept as is in `.kiro/settings/mcp.json`.
- The Vitest docs site timed out during setup (two attempts). The config uses only long-stable options (`defineConfig` from `vitest/config`, `test.include`) and was verified by running it.

## Database notes

- Import and migrations read `.env` from the repo root and use only `DATABASE_URL_UNPOOLED`. `DATABASE_URL` (pooled) is for app runtime in later phases.
- `pg` prints a warning that `sslmode=require` currently behaves like `verify-full` and will change in pg 9. The strings Neon gives work today. To keep the current behaviour after a future upgrade, put `sslmode=verify-full` in both strings.
- The Neon dev branch is `dev-skeleton-core` (`br-blue-breeze-arxdc1lo`) in project `kiroween-2026` (`restless-silence-44986466`). The default branch was left empty on purpose (R3.3).
- Known advisory: drizzle-kit 0.31.11 bundles `@esbuild-kit/*` with esbuild 0.18.20 (moderate, esbuild dev server). Dev tool only; no dev server is run.

## Hooks

Kiro IDE 1.0 and later load hooks from `.kiro/hooks/<id>.json` (`"version": "v1"`, PascalCase triggers, `action.type` `command` or `agent`). The Phase 0 hook was converted to this format. Files: `content-validate.json` (agent action on save of `content/legends/*.md`) and `skeleton-tests.json` (command action on save of `skeleton/src/**/*.ts`).
